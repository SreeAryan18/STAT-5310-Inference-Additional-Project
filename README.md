# 🔍 EM Algorithm for Missing Value Imputation in Bivariate Normal Data

This repository contains an implementation of the **Expectation-Maximization (EM) algorithm** for imputing missing values in a dataset assumed to follow a **bivariate normal distribution**. The dataset involves paired response times to two stimuli: **Stimulus A** and **Stimulus B**.
